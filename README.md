# Bayburt Korsan Taksi

Bayburt korsan taksi üç ilçeli küçük bir ilde uzun yollar yapar. Şehirde havalimanı olmadığı için yolcu Erzurum'a taşınır: Bayburt merkezden 117 kilometre, 1 saat 29 dakika. Aydıntepe'den çıkanlar için Trabzon Havalimanı 114 kilometreyle bir seçenektir.

Çoruh kıyısındaki kale, Aydıntepe'deki yeraltı şehri ve köy yolundaki Baksı Müzesi aynı güne sığar. Demirözü'nden Erzurum Havalimanı 148 kilometre, 2 saat 1 dakikadır. Gümüşhane ve Erzincan yönüne de tek yön sefer yapılır.
